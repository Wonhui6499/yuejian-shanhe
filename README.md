# 阅见山河｜跟着答题去旅行

一个面向移动端的中国旅游文化互动知识答题网页。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 发布为网站

在 GitHub 仓库进入 **Settings → Pages**，将 **Build and deployment** 设置为 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，点击 Save。部署完成后可通过 `https://wonhui6499.github.io/yuejian-shanhe/` 访问。

## 功能

- 14 道中国自然风光与人文风物知识题
- 即时判题、答案解析与答题计分
- 完成后生成旅行家称号
- 无需登录，不收集或保存个人成绩
- 自适应手机屏幕
